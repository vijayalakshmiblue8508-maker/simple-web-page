Simple Login & Landing Page Project
📌 Project Overview

This project is a simple front-end Login Authentication System built using:

HTML

CSS

JavaScript

It includes:

A Login Page

A Landing (Welcome) Page

Basic credential validation using JavaScript

Simple and attractive UI design

📁 Project Structure
project-folder/
│
├── log.html        → Login Page
├── lan.html        → Landing Page (after login)
├── style.css       → Styling file
├── scriptt.js      → JavaScript logic
└── README.md       → Project documentation
🚀 Features

✅ User Login Form
✅ Username & Password validation
✅ Redirect to landing page after successful login
✅ Alert message for invalid login
✅ Logout functionality
✅ Modern gradient background design
✅ Responsive centered layout

🔑 Login Credentials

Username: admin
Password: 1234

➡ Redirects to lan.html

If incorrect:

🧠 How It Works
🔹 login() Function

Gets username and password values.

Checks if:

user === "admin" && pass === "1234"

If true → redirects to landing page.

If false → shows error alert.

🔹 logout() Function

Redirects user back to login page.
